# Тише — маленькие путешествия

Три страницы о коротких поездках: к морю, в горы и в лес. На каждой странице ровно три смысловых блока. Адаптивная вёрстка на HTML и CSS.

## Просмотр

Откройте `dist/index.html` в браузере. Навигация связывает все три страницы.

## Сборка

Требуется Node.js. Выполните `node build.cjs` из корня проекта. Генератор использует данные и шаблоны из `build.py`; установка Python не требуется.
